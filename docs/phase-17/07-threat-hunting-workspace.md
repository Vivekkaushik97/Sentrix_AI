# Phase 17: Threat Hunting Workspace

## Overview
Specified the frontend analyst hunting workflow.

## UI Requirements
- Analysts can search for IOCs and traverse the related `threat_campaigns`.
- Allows viewing timeline events natively associated through `threat_indicator_correlations`.
- Context from the hunting workspace is fed directly to the AI Assistant for detailed, data-grounded summaries, strictly enforcing that AI cannot be the source of truth, only the interpreter.
