# Phase 17: Threat Intelligence Operations Model

## Overview
Defined rigorous enumerations preventing arbitrary string-based data corruption across the threat platform.

## Bounded Enumerations
- **IOC States:** `NEW`, `ACTIVE`, `EXPIRED`, `FALSE_POSITIVE`, `SUPPRESSED`, `ARCHIVED`.
- **Confidence Levels:** `UNKNOWN`, `LOW`, `MEDIUM`, `HIGH`, `CONFIRMED`.
- **Threat Classifications:** `MALWARE`, `PHISHING`, `BOTNET`, `C2`, `RANSOMWARE`, `CREDENTIAL_ATTACK`, `FRAUD`, `SUSPICIOUS`, `UNKNOWN`.
