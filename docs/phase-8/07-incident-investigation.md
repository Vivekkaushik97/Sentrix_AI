# Phase 8: Incident Investigation

## Overview
The Incident Investigation UI creates a top-level `/incidents` view exposing the `SecurityIncident` case files generated by the `IncidentEngine`.

## Functionality
- Details risk score, severity, event timeline.
- Expandable sections detail which specific rules contributed to the incident severity.
- Connects disparate entities (e.g. UPI and Windows Events).
