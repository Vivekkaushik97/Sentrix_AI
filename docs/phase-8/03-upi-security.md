# Phase 8: UPI Security Intelligence

## Overview
A dedicated `com.sentrix.ai.upi` module introduces deterministic fraud detection for Real-time UPI payments, expanding Sentrix AI beyond just IT log analysis and into financial cybersecurity.

## Abstractions
- **`UpiTransaction`**: normalized entity covering VPA, device, amount, and IP.
- **`UpiFraudRule`**: interface allowing independently testable rule behaviors (e.g., `UpiVelocityRule`).
- **`UpiFraudEngine`**: evaluates incoming transactions against history.

## Policy
The engine strictly analyzes explicit data fields. Zero fake transactions are generated. Any risk score generated by the engine is bounded and fully explainable via the `UpiRuleDetection` return object.
