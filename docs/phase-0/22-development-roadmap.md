# Development Roadmap

Implementation order for Sentrix AI dependencies:

* **Phase 1 — Foundation**: Spring Boot setup, React setup, Git config.
* **Phase 2 — UI/UX Design System**: Tailwind, shadcn components, layout.
* **Phase 3 — Database Implementation**: Supabase setup, JPA entities, Flyway/Liquibase migrations.
* **Phase 4 — Security + Anonymous Sessions**: Spring Security config, Redis integration, UUID cookies.
* **Phase 5 — UPI Fraud Detection**: ML library integration, prediction endpoints.
* **Phase 6 — Windows Event Log Analysis**: EVTX parser integration, synchronous endpoints.
* **Phase 7 — CVE Intelligence**: External API client, local caching.
* **Phase 8 — AI Cybersecurity Assistant**: Spring AI setup, base LLM connectivity, chat UI.
* **Phase 9 — RAG**: pgvector setup, document ingestion service.
* **Phase 10 — Context-Aware Intelligence**: Linking RAG context to the Chat Assistant.
* **Phase 11 — Redis Optimization**: Caching layer for CVEs/aggregations.
* **Phase 12 — RabbitMQ Background Processing**: Refactoring Event Logs to async, worker configuration.
* **Phase 13 — Dashboard Intelligence**: Aggregation APIs, React charts.
* **Phase 14 — Security Reports**: PDF generation library, async report generation.
* **Phase 15 — Analysis History**: History API, frontend pagination.
* **Phase 16 — Testing**: Unit tests, integration tests.
* **Phase 17 — Security Hardening**: Final review of CORS, validation, rate limiting.
* **Phase 18 — Docker**: Containerization of Backend and Frontend.
* **Phase 19 — Nginx**: Reverse proxy setup.
* **Phase 20 — Monitoring**: Actuator, Prometheus, Grafana.
* **Phase 21 — Cloudflare**: Edge protection setup.
* **Phase 22 — CI/CD**: GitHub Actions deployment pipelines.
* **Phase 23 — Final Integration**: End-to-end testing and delivery.
