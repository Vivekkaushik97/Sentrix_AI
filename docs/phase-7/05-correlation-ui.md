# Phase 7: Correlation UI

## Overview
Displays sequential event chains linked by the `CorrelationEngine`.

## Layout
- Features an orange-accented card indicating correlated threat activity.
- Displays the `Correlation Key` (e.g., `AUTH_BRUTE_SUCCESS_Administrator`).
- Renders the chronological list of events (e.g., Event ID 4625 followed by 4624) embedded directly in the correlation card for rapid SOC triage.
