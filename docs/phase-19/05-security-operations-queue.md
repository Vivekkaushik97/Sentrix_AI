# Phase 19: Security Operations Queue

## Overview
Defined the analyst-facing operational triage structure.

## Queue Categories
- **Pending Approvals:** Actions in `PENDING_APPROVAL` state.
- **Critical Threats:** Incidents possessing an `aggregated_risk_score` >= 90.
- **Active Hunts:** Threat hunts in `RUNNING` status.

## Integrity
- The queue is generated by live SQL queries over `security_incidents`, `security_actions`, and `threat_hunts`. 
- Empty states legitimately display "No active operational items."
